# Mes skills Claude Code

Mes skills personnels pour [Claude Code](https://claude.com/claude-code). Chaque dossier est un skill : on le copie dans `~/.claude/skills/` pour l'utiliser.

| Skill | Sert à |
|---|---|
| `brind-build` | Met la branche principale à jour, puis (après accord) construit et publie en production. |
| `brind-embellir` | Améliore l'UI, l'UX, la responsivité et l'intuitivité d'une page ou d'un composant. |
| `brind-next` | Repère le prochain sujet le plus important du projet quand on a fini le précédent. |
| `brind-publier` | Met les modifications sur une nouvelle branche, les commite et les pousse. |
| `continuous-learning` | Relit les sessions passées pour en tirer des consignes durables, à valider puis à mémoriser. |
| `do-all` | La chaîne complète sans rien redemander : commit, fusion, version, build, déploiement, vérification. |
| `instincts` | Apprentissage continu local à partir des observations d'un hook (`ll.py`). |
| `optimiser-requetes` | Mesure puis réduit les requêtes d'une route ou d'un écran lent (N+1, appels en trop). |

Certains skills citent mon projet et ses dossiers (`do-all`, `optimiser-requetes`) : à adapter avant de les réutiliser.
